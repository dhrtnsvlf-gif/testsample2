# 오리엔트 공정불량 Manager (웹 버전)

데스크톱 프로그램(PyQt6) 사양을 FastAPI 웹 앱으로 옮긴 것입니다. 엑셀 파일(`.xlsx`, `.xlsm`)을 그대로 데이터 저장소로 씁니다.

## 실행 방법
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
브라우저에서 http://localhost:8000/ 에 접속합니다. 같은 네트워크의 다른 PC에서는 `http://<서버IP>:8000/`으로 접속합니다.

> 서버는 **프로세스 하나**로 실행해야 합니다(`--workers` 옵션 사용 금지). 저장 충돌을 막는 잠금이 프로세스 안에서만 동작합니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `main.py` | FastAPI 서버 (API, 설정값 `CAUSE_HEADER`·`DATE_HEADER`·`DIM_HEADERS`·`MAX_CARDS`·`DIM_TOP`) |
| `store.py` | 엑셀 읽기/쓰기, 자료형 판별, 백업, 동시 수정 충돌 확인 |
| `static/index.html` | 화면 |
| `static/app.js` | 화면 동작 (설정값 `ACCENTS`·`ROW_TINT`·`CELL_TINT`) |
| `static/style.css` | 전체 색상·모양 (사양서의 `STYLE`) |
| `data/` | 엑셀 파일 폴더 (환경변수 `DATA_DIR`로 변경 가능) |
| `config.json` | 마지막으로 연 파일 이름 (자동 생성, 지우면 초기화) |
| `data/*.xlsx.bak` | 서버 실행 후 파일별 첫 수정 직전의 자동 백업 |

## 데스크톱 사양과 다른 점
| 사양 | 웹 버전 |
|---|---|
| 파일 선택 창 / `config.json` 기억 | 서버 `data/` 폴더의 엑셀 목록에서 선택하거나 새 파일을 올림. 마지막 파일은 브라우저별로 기억하고, 처음 접속한 브라우저는 `config.json`의 파일을 엶 |
| 엑셀에서 열려 있으면 저장 안 됨 | 서버 파일에 쓸 수 없으면 같은 안내를 표시 |
| (해당 없음) | **여러 명 동시 사용**: 저장 직전에 그 행이 폼을 연 뒤로 바뀌었는지 확인하고, 바뀌었으면 저장하지 않고 안내. 다른 사람이 저장한 내용은 5초 안에 자동 반영 |
| `Ctrl+N` 신규 입력 | Chrome·Edge는 `Ctrl+N`을 새 창 열기로 먼저 처리하므로 `＋ 입력` 버튼을 사용 |
| 날짜 선택 | 기준일·기간은 브라우저 달력 사용 |

그 밖의 기능(목록·정렬·원인 카드·검색·조회/입력/수정/삭제·기간 조회·대시보드·단축키)은 사양서와 같습니다.
